# Telegram MVP-бот для регистрации на мероприятие брокеров/партнёров недвижимости

Демо-проект на **Python 3.12 + aiogram 3**, который выглядит как готовое бизнес-решение для клиентской презентации.
Бот даёт информацию о событии, проводит регистрацию в пошаговом формате, выдаёт материалы и отправляет напоминания перед мероприятием.

---

## Что умеет бот

### Пользовательский функционал
- `/start` — приветствие и главное меню.
- Главное меню с разделами:
  - О мероприятии
  - Программа
  - Спикеры
  - Место проведения
  - Зарегистрироваться
  - Получить материалы
  - Контакты
- Пошаговая регистрация через FSM:
  - ФИО
  - Телефон
  - Email
  - Компания
  - Должность
  - Город
  - Согласие на обработку данных
- Защита от повторной регистрации.
- Проверка корректности email и непустого телефона.
- После успешной регистрации:
  - запись в SQLite,
  - внутренний ID заявки,
  - подтверждение пользователю,
  - выдача материалов (текст + файл из `materials/`).
- `/my_registration` — просмотр своих регистрационных данных.
- `/cancel` — отмена регистрации на любом шаге.
- Если нажать «Получить материалы» до регистрации — бот вежливо попросит сначала зарегистрироваться.

### Напоминания о мероприятии
- Планирование напоминаний только для зарегистрированных пользователей:
  - за 7 дней,
  - за 3 дня,
  - за 1 день.
- Если до события меньше 7 дней — автоматически отправляются только актуальные напоминания.
- Планировщик: **APScheduler**, режим бота: **long polling**.

### Админ-функционал
- Доступ по `ADMIN_IDS` из `.env`.
- `/admin` — краткое меню администратора.
- `/stats` — общее число регистраций.
- `/registrations` — последние регистрации.
- `/export_csv` — выгрузка заявок в CSV.
- `/broadcast` — пример рассылки по зарегистрированным.

## Как создать `.env`

1. Скопируйте шаблон:

```bash
cp .env.example .env
```

2. Заполните переменные.

### Переменные окружения
- `BOT_TOKEN` — токен Telegram-бота.
- `ADMIN_IDS` — список Telegram user_id администраторов через запятую.
- `DATABASE_PATH` — путь к SQLite-файлу.
- `EVENT_DATETIME` — дата/время события в формате `YYYY-MM-DD HH:MM`.
- `TIMEZONE` — таймзона (например, `Europe/Moscow`).

Пример:

```env
BOT_TOKEN=123456:ABCDEF_your_token
ADMIN_IDS=111111111,222222222
DATABASE_PATH=database/event_bot.db
EVENT_DATETIME=2026-09-25 10:00
TIMEZONE=Europe/Moscow
```

---

## Как получить `BOT_TOKEN` через BotFather

1. В Telegram откройте `@BotFather`.
2. Введите команду `/newbot`.
3. Укажите имя бота (display name).
4. Укажите username (должен заканчиваться на `bot`).
5. Получите токен и вставьте его в `.env` в `BOT_TOKEN`.

## Как проверить работу

1. Открыть бота и нажать `/start`.
2. Пройти разделы меню («О мероприятии», «Программа», «Спикеры» и т.д.).
3. Пройти регистрацию через кнопку «Зарегистрироваться».
4. Убедиться, что:
   - пришло подтверждение с ID заявки,
   - выданы материалы,
   - команда `/my_registration` показывает сохранённые данные.
5. Проверить админ-команды под админским аккаунтом из `ADMIN_IDS`.

## Как сменить информацию о мероприятии

Все тексты и параметры события хранятся в `config.py` в `EventConfig`:
- название,
- подзаголовок,
- описание,
- место,
- программа,
- спикеры,
- контакты,
- текст материалов.

Дата и время мероприятия задаются через `.env` (`EVENT_DATETIME`).

## Как работают напоминания

- При регистрации пользователя бот создаёт отложенные задачи APScheduler.
- Точки отправки: `-7`, `-3`, `-1` день от `EVENT_DATETIME`.
- Если текущая дата уже позже соответствующей точки, напоминание пропускается.
- При старте бота планировщик перепланирует напоминания для уже зарегистрированных пользователей.

## Развёртывание на VPS (Ubuntu)

1. Установить Python 3.12 и git.
2. Клонировать проект.
3. Создать `.venv`, установить зависимости.
4. Создать `.env`.
5. Проверить локальный запуск `python bot.py`.
6. Настроить `systemd`-сервис (рекомендуется) для автостарта.

Пример unit-файла `/etc/systemd/system/realty_event_bot.service`:

```ini
[Unit]
Description=Realty Event Telegram Bot
After=network.target

[Service]
Type=simple
User=ubuntu
WorkingDirectory=/home/ubuntu/my_tg_bot
Environment="PATH=/home/ubuntu/my_tg_bot/.venv/bin"
ExecStart=/home/ubuntu/my_tg_bot/.venv/bin/python /home/ubuntu/my_tg_bot/bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

Активация:

```bash
sudo systemctl daemon-reload
sudo systemctl enable realty_event_bot
sudo systemctl start realty_event_bot
sudo systemctl status realty_event_bot
```
